Navestigio

Siga los vestigios del usuario en History, Login Data, Web Data, Cookies y Firefox, con todas las fechas en hora local.

Arrastre aquí History, Login Data, Web Data, Cookies, Favicons, Shortcuts, Top Sites, Bookmarks, Preferences, Local State, places.sqlite…
O use «Abrir carpeta de perfil…» para cargar todo el perfil de una vez.
Incluya los archivos -wal si existen: guardan los registros más recientes y se aplican automáticamente.

Los archivos se leen dentro de este navegador y no se envían a ningún servidor. La evidencia original no se modifica: se calcula su SHA‑256 y se trabaja sobre una copia en memoria.

Las fechas del resultado también se convierten.

Reglas de alerta

Una categoría por línea: Nombre: palabra1, palabra2, …. Se busca cada término como palabra completa (sin distinguir mayúsculas) en todas las columnas de la fila, con las URL decodificadas y sin los bloques codificados largos (tokens, base64). Con * al final es prefijo (homofob*); con punto es dominio o extensión (pornhub.com, .exe). Pasa el mouse sobre una etiqueta para ver qué término coincidió. Las descargas con advertencia de peligro (danger_type distinto de 0) se marcan siempre.

Convertir valores sueltos

Pegue uno o varios timestamps, separados por espacio, coma o salto de línea.
